# Verify Before You Assist

An interactive, self-paced micro-learning module that trains customer-support agents to **verify identity before sharing personal or order data**, across email and live-chat channels.

**▶ Live demo:** `https://mohababoserie.github.io/verify-before-you-assist/`

---

## What learners practice

| Topic | Activity type |
|---|---|
| GDPR basics — personal data goes only to its owner or someone they authorize | Concept intro |
| The golden rule of verification | Swipe-card game |
| Email channel: matching sender details to the order record | Inspector / scan simulation |
| No order number? Searching the mailbox to find the record | Mail-app simulation |
| Gifts & receivers — who counts as the customer | Pick-one scenarios |
| Authorized sellers, club membership, email typos | Branching chat simulations |
| Live chat verification | Role-reversal ("be the customer") simulation |
| Mixed review | Speed round + quick checks with points |

## Instructional design notes

- **Scenario-first:** every rule is practiced in a realistic customer interaction before it is summarized.
- **Immediate feedback:** each choice shows why it is right or wrong, not just a score.
- **Gamified progression:** points, streak-style speed round and a one-lesson-at-a-time dock keep the cognitive load low.
- **Job-ready:** activities mirror the actual tools agents use (mail client, chat, order record).

## Run it

It is a single, self-contained HTML file — no build step, no install.

- **Online:** open the GitHub Pages link above.
- **Offline:** download `index.html` and open it in any modern browser.

## Reuse & adapt

All customer names, emails and orders in the module are fictional. Fork the repo and edit `index.html` to swap in your own policy rules, scenarios or branding.
